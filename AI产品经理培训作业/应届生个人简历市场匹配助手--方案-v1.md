## 0. 修订总览

原始草案存在以下致命问题，经 12 刀质询后逐一修订：

| 原草案 | 问题 | 修订后 |
|---|---|---|
| 所有高校 + 本/研/专 | 用户群体过大，三类学历诉求差异巨大 | **聚焦研究生**（学历溢价最高） |
| 所有求职渠道（默认） | 研究生求职主战场在公开网站之外 | **仅公开招聘市场**（BOSS/智联/拉勾/猎聘/51job）|
| web 爬取 | 法律风险 + 技术对抗 + 数据规模不可行 | **第三方聚合 + 官方 API 补齐** |
| 4 维度匹配（岗位名称/技能/城市/公司） | 缺薪资下限、户口、研究方向 | **6 维度**，研究方向用行业赛道暂代 |
| 79 元/月 500 次单一定价 | 价值单一、对比 BOSS 168 元无竞争力 | **分层定价 49 / 99 / 199** |
| Web + App + 小程序三端并行 | 6–8 个月开发周期，MVP 必死 | **App + H5**，二期加小程序 |
| 每周推送 100 条 | 用户疲劳，触达衰减 | **每周 15–25 条** |
| 80% 用户确认投送（伪 KPI） | 口径模糊、不可衡量 | **投递转化率 ≥ 20%** |
| 用户自己沟通（无差异化） | 缺乏付费动机 | **AI 招呼语模板 + 手动复制** |
| AI 自动打招呼 | 合规风险极高、平台账号封禁 | **MVP 跳过，先做 demo 迭代** |

## 1. 范围与边界（明确取舍）

| 取舍 | 决策 | 代价 |
|---|---|---|
| **目标用户** | 研究生群体 | 排除本科生、专科生 |
| **求职渠道** | 仅公开招聘市场 | 排除校招 / 内推 / 选调生 / 事业单位 |
| **研究方向匹配** | MVP 用"行业赛道标签"暂代 | 推送质量有损失，二期补 |
| **AI 自动打招呼** | MVP 跳过，先做 demo 再迭代 | 业务差异化减弱，二期评估 |

---

## 2. 用户画像（清晰定义）

- **核心用户**：985/211 + 双一流院校在校研究生（硕士、博士）
- **专业偏好**：CS / EE / AI / 半导体 / 生物医药 / 金融硕士为前 5 大群体
- **地域偏好**：一线 + 新一线（北/沪/广/深/杭/蓉/宁/苏）
- **毕业时间窗**：毕业前 6–18 个月（求职黄金期）
- **付费意愿锚点**：BOSS 会员 168 元/月 vs 本产品 49/99/199 元/月

---

## 3. 数据获取

- **主源**：第三方招聘数据聚合服务（薪乐宝、职涯宝类）+ 5 大平台官方 API 补齐
- **覆盖**：≥ 85% 公开岗位池
- **单条成本**：0.03 元/条（按调用计费）
- **采集频率**：每日全量 + 增量更新
- **风险标注**：单源宕机时备用切换路径需在二期补充

---

## 4. 匹配规则（MVP）

| 维度 | 权重 | 数据来源 |
|---|---|---|
| 行业赛道标签 | 30% | 用户填写偏好 |
| 薪资下限 | 25% | 用户设定底线 |
| 户口 / 编制 | 15% | 岗位标签识别 |
| 岗位名称 | 15% | 用户简历关键词 |
| 技能要求 | 10% | 用户简历 + 行业词库 |
| 公司 | 5% | 用户白/黑名单 |
| **研究方向** | **暂用赛道代替** | **二期补** |

---

## 5. 定价（分层 49 / 99 / 199）

| 套餐 | 价格 | 功能 | 目标用户 |
|---|---|---|---|
| **基础版** | 49 元/月 | 每周推送 15–25 条、AI 招呼语模板、一键复制 | 大多数研究生 |
| **进阶版** | 99 元/月 | 基础 + 主动沟通话术、简历润色、行业薪资报告 | 高活跃用户 |
| **尊享版** | 199 元/月 | 进阶 + 1 次人工简历修改、面试模拟、行业导师答疑 | 冲刺 Offer 用户 |

> 取消"首月 1 元"诱导定价，规避合规风险。

---

## 6. 产品形态（MVP）

- **首推**：App（iOS + Android，含系统 Push 推送）
- **配套**：H5 轻量版（PC 可访问，移动浏览器可快速体验）
- **二期**：微信小程序（微信生态接收通知）
- **跨端框架**：uni-app（一次开发，三端复用）

---

## 7. 业务流程（MVP 简化版）

```
用户上传简历 → 填写偏好画像（行业 / 薪资 / 地域 / 户口）
        ↓
数据层：第三方聚合 + 官方 API 采集（每日）
        ↓
匹配引擎：按权重打分 → 生成 Top 20 推送
        ↓
App Push：每周一 9:00 推送
        ↓
用户查看 → 点"感兴趣" → 生成招呼语模板 → 手动复制到招聘平台
        ↓
反馈回流：用户标记"已投递 / 已查看 / 无感" → 优化匹配模型
```

### MVP KPI（替代原"80% 确认投送"）

- **投递转化率 ≥ 20%**（推送 20 条，至少 4 条被标记"想投递"）
- **次月留存率 ≥ 35%**
- **单用户 ARPU ≥ 60 元**

| 风险 | 等级 | 二期缓解 |
|---|---|---|
| 研究方向匹配缺失导致推送质量下降 | 🟡 中 | 二期补论文解析 + 关键词提取 |

| App 上架审核延迟 | 🟡 中 | 同步上架 H5，App 审核期间不空窗 |
| 跨平台账号风控（用户自己账号被封） | 🟠 高 | MVP 阶段禁止任何"AI 代操作"功能，仅文案辅助 |
